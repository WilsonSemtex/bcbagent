## 一、阅图总纲（人类判读原则）
- **1. 矢量优先，视觉辅助：DXF 是矢量图纸。所有尺寸、孔径、圆角、凹角均以坐标/实体数据为精确依据；GLM 等视觉模型仅用于理解图纸整体布局与判断特征类型，不直接采信其数字。**
- **2. 以“冲压板材”语义解读轮廓：看到封闭闭合环即判定为孔/腔体；看到轮廓上的内凹、缺口、槽即判定为内凹角；对圆角需区分“外轮廓圆角”与“孔/槽端部圆角”。**
- **3. 孔径 = 圆的直径，而非半径：读圆孔时优先报告直径；跑道形/长圆孔需同时给出孔宽、总长与端部圆角半径。**
- **4. 视觉读数可能有数量级误判：视觉模型对尺寸有误读风险（如 60 读成 6000、100 读成 10000），必须回查矢量坐标校准。**
- **5. 标注“不确定项”：对无法由 2D 线框唯一判断的项目（如封闭轮廓是孔还是凸印、单位是毫米还是英寸）不得臆断，应明确标注为“未定/需人工确认”。**
- **6. 装配孔语义：板材上的圆孔通常为装配孔。装配孔判定基准为“国标常用螺钉直径表”（见“缺陷评分规则”章节）。正确孔径区间 = 最邻近钉径 D + [0.1, 0.3]mm（余量用于配合）。如 φ3.2mm 对应 M3.0 钉，落在 [3.1, 3.3]，是正确画法。**
- **7. 凸形板材可免外圆角：若板材所有外角均 >180°（无内拐角、呈凸多边形），边与边过渡处的圆角可省略；此时缺圆角仅构成轻微缺陷“过渡不平滑”(1分)，而非硬性错误。**
- **8. 圆角须统一绘制：若绘图者决定给轮廓转角加圆角，则应对所有角统一加圆角。只给部分角加圆角(如 5 角只画 2 角)即构成缺陷“过渡圆角不全/遗漏”(F09, 1分)。**
- **9. 同批孔径须一致：同一板材或同一批次的全部圆孔应使用相同直径，以保证装配误差一致。孔径不一致(即使各孔单看都合格)即构成缺陷“同批次孔径不同”(F06, 2分)。**
- **10. 大圆孔豁免螺钉评价：直径明显大于 8mm 的孔(如 φ14 通孔)不是螺钉装配孔，不套用螺钉表/F05/F04/F06 评价；按一般通孔(穿线/过轴/让位)处理，不判定缺陷。**
- **11. 三角形镂空孔豁免缺陷检测：“先画方形孔、再在孔内斜插两条肋板补强”形成的三角形镂空孔是常用镂空结构，由方孔 + 两条斜肋板构成(各角常带小圆角如 R1.5 过渡)，不作为缺陷，不需检测。**
- **12. 骨头棒装配孔：骨头棒孔用于与另一块带矩形凸起的板装配：凸起嵌入该孔。因三轴雕刻刀(圆形)无法加工矩形内角,在矩形长边四角加四个过渡半圆。读取时分两元素：①矩形孔(长=整+0.3,宽=板厚+0.1)；②过渡半圆(直径≥刀具直径)。**
- **13. 钉孔间距校核：同一板多个螺钉固定孔之间的间距必须大于对应螺钉的钉头直径(见螺钉表 H 列)。校核孔大小后还须读取全部固定孔间距并与钉头直径比较：任两相邻孔间距 ≤ 钉头直径即触发钉头干涉错误(F03, 8分)。例：3mm 钉钉头直径 6mm，固定孔间距须 ≥6mm。**
- **14. 骨头棒必带过渡圆弧：骨头棒矩形孔四角必须有过渡半圆(圆刀无法加工 90° 内角)。若仅绘成纯矩形尖角而无过渡圆弧，则无法加工，触发 F01 骨头棒孔形错误(9分)。**
- **15. 榫头(配合骨头棒孔)：板材边缘向外凸出的矩形凸块即榫头，用于嵌入另一块板上的骨头棒孔完成装配。结构与骨头棒孔同源：矩形凸起 + 两侧在方形内角相切处画两个过渡半圆。识别到矩形凸起即认定榫头；其长=矩形直线段长、宽=板厚(2/3/4 高频)。**
- **16. 内镂空孔需过渡圆角：内部镂空/异形孔的内角必须带过渡圆角，否则刀路受刀具限制自动生成过渡圆角，孔形与设计不符。内角全为尖角即触发 F07 缺少内部过度圆角(2分)。**
- **17. 榫头必带过渡圆弧：骨头棒榫头两侧方形内角必须画过渡半圆(圆刀无法加工 90° 内角)。若榫头纯矩形尖角而无过渡圆弧，无法扣入孔，触发 F02 骨头棒榫头过渡圆弧缺失(9分)。**

## 二、判读评价指标体系

| 指标 | 说明 | 权重 |
|------|------|------|
| M1 特征识别完整性 | 能否覆盖：全部孔、全部圆角、全部内凹角、整体轮廓。漏项记为缺陷。 | 10 |
| M2 数值精确度 | 孔径/半径/尺寸的数值是否与矢量解析一致，数量级是否无误。 | 10 |
| M3 语义正确性 | 是否正确区分孔 vs 圆角 vs 凹槽、外圆角 vs 端部圆角、孔 vs 凸印。 | 10 |

## 二·试、缺陷评分规则（严重度 0-10）
装配孔判定基准：以国标常用螺钉直径表代替“整数”近似。

| 螺钉规格 | 公称直径 D (mm) | 正确孔余量区间 (mm) | 钉头直径 H (mm) |
|----------|------------------|----------------------|------------------|
| M1.0 | 1.0 | 1.1 ~ 1.3 | 2.0 |
| M2.0 | 2.0 | 2.1 ~ 2.3 | 3.5 |
| M2.5 | 2.5 | 2.6 ~ 2.8 | 4.5 |
| M3.0 | 3.0 | 3.1 ~ 3.3 | 6.0 |
| M3.5 | 3.5 | 3.6 ~ 3.8 | 6.5 |
| M4.0 | 4.0 | 4.1 ~ 4.3 | 7.5 |
| M4.5 | 4.5 | 4.6 ~ 4.8 | 8.0 |
| M5.0 | 5.0 | 5.1 ~ 5.3 | 9.0 |
| M6.0 | 6.0 | 6.1 ~ 6.3 | 10.5 |
| M7.0 | 7.0 | 7.1 ~ 7.3 | 11.5 |
| M8.0 | 8.0 | 8.1 ~ 8.3 | 13.5 |
装配孔判定基准：以国标常用螺钉直径表代替“整数”近似，常用钉径为 M1.0(1.0), M2.0(2.0), M2.5(2.5), M3.0(3.0), M3.5(3.5), M4.0(4.0), M4.5(4.5), M5.0(5.0), M6.0(6.0), M7.0(7.0), M8.0(8.0)。正确孔径区间 = 最邻近螺钉直径 D + [0.1, 0.3] mm。落在区间内→正确；低于下限→F05(3分,配合过紧/装配困难)；高于上限→F04(5分,配合过松/可靠性不足)。非标孔按最接近钉径匹配判定。钉头间距校核：同一板多个螺钉孔间距必须 > 对应钉头直径(见下表)，否则钉头干涉触发 F03(8分)。
缺陷排序总览（按严重度从高到低）：

| 缺陷编号 | 缺陷名称 | 严重度 |
|----------|----------|--------|
| F01 | 骨头棒孔形错误 | 9 |
| F02 | 骨头棒榫头过渡圆弧缺失 | 9 |
| F03 | 钉孔距离过小 | 8 |
| F04 | 孔余量过大 | 5 |
| F05 | 孔余量过小 | 3 |
| F06 | 同批次孔径不同 | 2 |
| F07 | 缺少内部过度圆角 | 2 |
| F08 | 过渡不平滑 | 1 |
| F09 | 过渡圆角不全/遗漏 | 1 |
| F10 | 板厚疑似有误 | 1 |
- **F01 骨头棒孔形错误：骨头棒矩形孔必须带四个过渡半圆(圆刀无法加工矩形 90° 内角)。若骨头棒孔仅绘成纯矩形尖角而无任何过渡圆弧，则加工无法实现。严重度 9/10。判定：骨头棒矩形四角若无 ≥1 段圆弧即触发，输出“骨头棒孔形错误,无法加工”。**
- **F02 骨头棒榫头过渡圆弧缺失：骨头棒榫头(边缘凸起矩形)两侧方形内角必须画过渡半圆(圆刀无法加工 90° 内角)，否则刀具残留圆角使榫头无法扣入孔。严重度 9/10。判定：榫头矩形四角(两侧方形内角)无 ≥1 段圆弧即触发“骨头棒榫头过渡圆弧缺失,无法装配”。**
- **F03 钉孔距离过小：同一板材多个螺钉固定孔之间的间距必须大于对应螺钉的钉头直径，否则装钉时钉头互相干涉无法装配。严重度 8/10。判定：任两相邻螺钉孔圆心距 < 对应钉头直径(见表)即触发“钉孔距离过小”。例：3mm 钉钉头直径 6mm，固定孔间距须 ≥6mm；本类板若间距仅 5mm 即错误。**
- **F04 孔余量过大：内圆孔直径大于其最接近螺钉直径 D+0.3mm：配合过松、机构可靠性不足。严重度 5/10。判定：若 d>D+0.3 触发。**
- **F05 孔余量过小：内圆孔直径小于其最接近螺钉直径 D+0.1mm：配合过紧、装配困难。严重度 3/10。判定：对任意孔，取最接近的常用螺钉直径 D(表见下)，若 d<D+0.1 触发。**
- **F06 同批次孔径不同：同一板材(或同一批次)的圆孔直径应当一致，以保证装配误差统一。若各孔直径不相同(如 3.1/3.2/3.3mm 混用)，判定为同批次孔径不一致。严重度 2/10。判定：圆孔集合的直径出现 ≥2 个不同值即触发，无论单孔是否各自合格。**
- **F07 缺少内部过度圆角：内镂空/异形孔的内角若全部为尖角而无过渡圆角，则加工刀路会因刀具限制自动生成过渡圆角，导致孔形与设计不符。严重度 2/10。判定：内部闭合腔体的转角无 ≥弧即触发“缺少内部过度圆角”。**
- **F08 过渡不平滑：对全外角>180°的凸形板材，若边与边过渡处无圆角，判定为过渡不平滑。严重度 1/10。注：凸形无内拐角时，按本训练规范“缺圆角”属轻微缺陷(1分)，而非硬性错误。**
- **F09 过渡圆角不全/遗漏：若绘图者已对板材部分角绘制圆角，但并未对所有角统一绘制(如五边形只画了 2/5 个圆角)，判定为过渡圆角不全/遗漏。严重度 1/10。判定：轮廓角的圆角数量 < 轮廓总角数即为不全。**
- **F10 板厚疑似有误：骨头棒孔的宽度 = 配套板材厚度 + 0.1mm。若由孔宽反推的板厚为非 2/3/4mm 的其他整数，输出疑问“请问与其装配的板材厚度为多少?”，并判定缺陷“板厚疑似有误”。严重度 1/10。判定：2/3/4mm 为高频正确厚度，其余整数需疑。**

![./CASE-001.png](./CASE-001.png)

**整体轮廓：**
五边形固定板（凸多边形，所有外角>180°，无内拐角，整体凸形）。轮廓由 5 条直线构成，X∈[-100,-50], Y∈[-100,-50]。

**孔径与孔：**
7 个装配圆孔（CIRCLE 实体），全部直径 φ3.2mm（半径 1.6）。φ3.2 = 3.0 + 0.2，对应 M3.0 钉，落在 [3.1, 3.3] 标准区间，为正确画法。

**圆角半径：**
无。各边过渡处无圆角（凸形板材，无内拐角，圆角可省略）。

**内凹角：**
无。板材为凸多边形，无任何内凹角/缺口/槽。

**人类判读要点：**
典型固定板：多个装配孔用于安装。M3.0 钉对应 φ3.2 孔(+0.2 余量)是规范做法；由于是凸多边形，边角无圆角仍属正确，只记为轻微“过渡不平滑”(1分)而非错误。

**自动解析对比：**
自动解析：矢量读取到 7 个 CIRCLE，直径均为 3.2000mm，符合装配孔规范；5 条 LINE 构成凸五边形，无 ARC 圆角。GLM 视觉识别孔数为 6，且对顶部内凹弧的描述不精确——最终以矢量的 7 孔为准。

**经验沉淀：**
- 装配孔直径应检查是否落在对应螺钉直径的“D+0.1~0.3mm”区间；φ3.2 对应 M3.0 钉。
- 凸多边形(外角全>180°)无内拐角时，缺圆角只是轻微缺陷(1分)，不算画错。
- 视觉模型对孔数/微内凹有漏判误判，圆孔统计必须回查 CIRCLE 实体。

### 案例 CASE-002 —— 错误案例（两处谬误：过渡圆角不全 + 同批次孔径不同）

**附件图纸文件：**
原始图纸已复制到本 bcb 文件夹: `./CASE-002.dxf` (即 <bcb 文件夹>/CASE-XXX.dxf)。智能体应读取此 DXF 文件获取真实几何数据后再判断。原始来源: 本 bcb 文件夹 ./CASE-002.dxf

**外形图(PNG 供人工检阅)：**
图纸外形渲染见本 bcb 文件夹: `./CASE-002.png`。该 PNG 为 DXF 渲染视图，供人类检查者快速了解外形；详细几何仍以 .dxf 坐标为准。
![./CASE-002.png](./CASE-002.png)

**整体轮廓：**
五边形固定板（凸多边形，外角均>180°）。轮廓由 5 直线 + 2 圆弧构成，X∈[-100,-50], Y∈[-100,-50]。

**孔径与孔：**
7 个装配圆孔，但直径不一致：φ3.3×1、φ3.2×5、φ3.1×1。单孔各自落在 M3.0 钉 [3.1,3.3] 区间内（单独看均合格），但同批孔径混用 → 谬误。对应的半径值：1.65/1.60/1.55mm。

**圆角半径：**
圆角不全：五边形 5 个角仅 2 处画了 R2 圆角（左下角、右下角），其余 3 角为尖角。绘图者开始画圆角却未全部统一绘制 → 谬误 1。

**内凹角：**
无。凸多边形，无内凹角。

**人类判读要点：**
两处谬误：①过渡圆角不全——既然加圆角就该对所有角统一绘制(只画2/5角不一致)；②同批次孔径不同——同一块板应全部用同一孔径(3.1/3.2/3.3混用使装配误差不一致)。

**自动解析对比：**
矢量解析：CIRCLE 半径 1.55/1.60/1.65 分布明确辨识孔径 3.1/3.2/3.3 不一致；ARC 仅 2 个(R2)对应补角的圆角，5 角未全覆盖。GLM 视觉能看出圆角不全，但对 0.1mm 级孔径差异无法分辨，孔径一致性只能靠矢量坐标判定。

**经验沉淀：**
- 判定“过渡圆角不全”：圆角数量必须等于轮廓总角数，不足即触发 F09。
- 判定“同批次孔径不同”：圆孔直径出现≥2种不同值即触发 F06，无论各孔径单独是否合格。
- 孔径 0.1mm 级的差异(CIRCLE 半径 1.55/1.60/1.65)视觉模型读不出，必须回查 CIRCLE 半径值。

## 四、判读规则库（可复用规则）
- **R1 孔径报告用直径：圆孔一律报告(直径 d=2r)；长圆孔报告(宽度、总长、端部圆角 R)。**
- **R2 圆角三级分类：a) 外轮廓大圆角(≈90° 弧,大半径)；b) 孔/槽端部圆角(180° 半圆端)；c) 内凹槽过渡圆角。三种要分别统计。**
- **R3 孔型识别：完整 360°(或两段合 360°)同圆心同半径 → 圆孔；两条平行短直线+两端半圆 → 长圆孔；多弧+直线围合闭合环 → 异形孔。**
- **R4 内凹角识别触发：轮廓上出现 Y 方向或 X 方向的局部内凹段(缺口/槽/U形)即为内凹角，须报告：位置、宽度、深度、过渡圆角。**
- **R5 反例——视觉数字陷阱：当视觉给出数量级异常的数字(如 6000/10000)疑似把 60/100 放大时，回查矢量值。**
- **R6 单位诚实：无图框说明时单位未知，报告时标注‘单位未标注’，不默认毫米/英寸。**
- **R7 孔 vs 凸印：封闭闭合环默认判为孔；若该环尺寸明显小于整体且为装饰性对称，可能为压印/凸起，标注为‘待确认’。**
- **R8 骨头棒孔读取法：骨头棒孔拆成两元素读取：①矩形孔——长=两个短边(横线)间距离(=两过渡半圆直径+所夹线段长)，宽=两长竖线间距离(短边决定)；②过渡半圆——每矩形长边两端各一半圆。长=整数+0.3(整数对应配套凸起长度，不受表约束)；宽=配套板厚+0.1。**
- **R9 骨头棒刀具判定：过渡半圆直径应 ≥ 刀具直径(矩形内角需半圆过渡，圆刀无法切 90° 角)。读了半圆直径后取≤它的最大可加工刀具直径，输出“加工该板材应使用 Xmm 及以下的刀具”。**
- **R10 榫头读取法：榫头 = 板材边缘向外凸出的矩形凸块 + 两侧两个过渡半圆。拆两元素读取：①矩形凸起——长=凸块两短边间直线长，宽=板厚(凸出方向厚度)；②过渡半圆——矩形长边两端的方形内角相切处各一个。榫头长=整数(配合骨头棒孔长=整数+0.3)，宽=板厚+0 即板厚值。识别矩形凸起即认榫头。**
